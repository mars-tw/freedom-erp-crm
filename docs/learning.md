# 沉浸教學

建立測試工作區後，按「開始流程教學」，或從側欄進入「沉浸教學」。系統依目前啟用的模組提供商品銷售、服務交付及製造工單路線。

流程板會顯示章節、資料關係與目前結果。先讀「這一步會改變什麼」，再按「執行這一步」。每次只送出一個既有 API 操作；瀏覽章節、回答觀念題及播放動畫都不會修改工作區。教學所新增的客戶、買家、案件、訂單或工單會留在原本的功能頁，方便核對。

| 路線 | 練習結果 |
| --- | --- |
| 商品銷售 | 建立教學客戶與買家、補充 SIM、進貨、預留訂單、付款及出貨 |
| 服務交付 | 客戶與案件、報價版本、服務確認、交付、驗收及 SIM 收款 |
| 製造工單 | 補充 SIM、材料入庫、工單、備料、開工及 FIFO 完工成本 |

製造教學採用範本中的單一元件 BOM，方便逐步核對一筆材料入庫。多元件 BOM 可在製造模組操作，需逐項準備庫存。材料與成品的現有量分開顯示，完工前後可直接比對。

步驟完成需要本次教學的操作收據與工作區資料佐證，其他訂單或種子資料不會算成你的教學進度。重新整理或離開核對資料後，可在同一瀏覽器分頁回到原章節；觀念題答案、資料範圍與精簡畫面也會保留。閱讀狀態存在分頁的 sessionStorage，不跨裝置同步。瀏覽器禁止儲存時可繼續練習，但關閉或重新整理可能失去閱讀紀錄。清除、匯入或更換工作區後，教學重新開始，不能把上一個工作區的完成紀錄套進新資料。

「本輪練習」只統計這一輪建立的客戶、買家、訂單、案件或工單；商家測試幣與商品庫存屬共用資源，會明確標示。需要看全部紀錄時，切換「整個工作區」。範圍切換只改顯示，不執行操作。

每個新執行的步驟會保存本分頁操作時的前後讀值，回看舊章節仍可比較。快照必須對上本輪 checkpoint 與操作歷史，完成判定以收據及目前資料為準。未保存過的舊步驟不會補造歷史數字；原收據恢復時若工作區已有後續變動，也不把目前數字當作當時結果。

如果回應遺失，先按「確認原操作結果」。系統保留原操作的識別碼、參數與版本，收據確認成功才更新進度。不要為了等待回應而再開一筆交易。

「暫停教學」停止教學操作與動態呈現，仍可離開查看各功能頁。裝置設定減少動態效果時，動畫會停用，所有操作與文字仍可使用。教學沒有自動執行交易的功能。

手機版把同一組主要操作固定在畫面底部，方便逐步實作。可開啟「精簡畫面」收起流程圖與開場內容；選章節及下一步後，焦點會移到章節標題。另開一輪會清除該輪閱讀偏好與快照，既有模擬業務資料保留。

所有金額固定為 SIM，所有商品與案件均為虛構練習。教學不是法遵、正式會計或真實付款訓練。八個範本共用已實作的流程，沒有宣稱每個行業都已完整驗證。

## 文案調整紀錄

| 原句／內容 | 調整原因 | 新內容 |
| --- | --- | --- |
| 工作總覽只有功能模組入口 | 新使用者不容易知道操作順序 | 新增「開始流程教學」及三條可實作路線 |
| 建立頁只介紹範本與 SIM | 未說明建立後如何練習 | 說明動態流程板與每一步的資料變化 |
| 操作手冊以功能清單為主 | 難以核對一次完整流程的結果 | 新增本文件，說明操作、收據、資料核對與接續限制 |
| 數字涵蓋整個工作區 | 種子資料與其他練習容易混在一起 | 預設顯示本輪紀錄，共用資源明確標示，另提供全工作區切換 |
| 只有最後一步顯示前後比較 | 重新整理與回看後難以核對 | 保存逐步讀值、原章節與閱讀偏好，缺少歷史時明說 |
