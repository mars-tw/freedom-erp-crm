# 設計模板：挑選自己的工作台外觀

[開啟八套模板圖庫](https://freedom-erp-crm-demo.digimkt.workers.dev/#design)。可從頂欄、左側「設計模板」，或「外觀設定」進入；還沒建立工作區也能先選外觀。

## 八種視覺風格

| 模板 | 主要版面 | 視覺特色 |
| --- | --- | --- |
| 深海商務 Harbor | 浮動導覽與內容外框 | 深海藍、青藍操作、雙欄工作卡；新瀏覽器的預設外觀 |
| 典雅企業 Executive | 分層側欄 | 石墨與金色細線、襯線標題、穩定留白 |
| 品牌工作室 Atelier | 上方模組列 | 梅紫與粉色、大字展示、非對稱圓角卡 |
| 活力店務 Commerce | 上方模組列 | 鈷藍與橙色、圓角商品格、寬幅店務入口 |
| 工廠控制室 Industrial | 工程側欄 | 板岩色、橙色指示、方角面板、工程分隔與技術數字 |
| 自然門市 Verdant | 浮動導覽 | 霧綠、寬留白與柔和圓角，適合門市及服務紀錄 |

八套都能搭配「淺色工作台」「深色工作台」「依系統設定」，以及舒適／精簡密度。模式與密度獨立保存，不因換模板被重設。縮圖是版面示意，工作台上的數字始終取自目前訪客的實際 SIM 紀錄。

## 試看、取消與套用

1. 用商務、店家、創意、工廠分類或字面搜尋，找到想看的模板。沒有結果時可清除搜尋與分類。
2. 按「試看這套」，整個畫面會即時改用該外觀，尚未保存。精選區的「到工作台看效果」可帶著目前資料試看總覽；尚未建立工作區時會顯示開始畫面，沒有自動建立資料。
3. 試看列可「取消試看」回到原模板，或「套用這套」保存。也可直接在卡片套用。試看時資料寫入暫停；套用或取消後可恢復操作。

返回設計圖庫可繼續試看；改去其他一般功能入口會取消尚未保存的試看。沒有表單或輸入框取得焦點時，Esc 也能取消。取消及套用後，焦點會回到可繼續操作的模板按鈕或設計入口。

## 保存範圍與資料

模板偏好只保存於這個網站、這個瀏覽器。重新整理後會讀回已套用的模板；清除 cookie、建立另一個 SIM 工作區或匯入 JSON 不會把外觀當成業務資料。公開網址與本機網址屬於不同網站來源，請在各自的圖庫選擇外觀；沒有跨裝置同步。

瀏覽器拒絕保存時，畫面仍可套用並明確顯示「目前只保留在本分頁」。關閉或重新整理分頁後可能恢復先前設定。未知模板或損壞的偏好會退回深海商務，不阻擋工作台。

模板選擇、搜尋、試看與套用不會建立訂單、付款、調整庫存、啟用產業模組或修改行政紀錄。它們也不包含登入權限、產業政策或新的業務功能；目前所有流程仍使用模擬資料與 SIM 測試幣。

介面使用原創 SVG 縮圖、圖示與本機字型 fallback，不下載外部字型或圖片。列印行政範圍報表會回到白底黑字，保留 SIM、日期、時區、篩選與資料來源；螢幕上的裝飾與試看列不列印。

## 擴充模板

目錄在 `web/design-templates.ts`，完整外觀在 `web/design-templates.css`，縮圖與圖庫在 `web/DesignStudio.tsx`。新增模板須同步嚴格識別、兩種配色、導覽布局、縮圖及資料不變測試，並實際檢查手機、對比、鍵盤與列印。新增外觀識別不會自動產生尚未實作的產業功能。

工作範圍見[設計模板計畫](../plan/design-template-studio-v1.md)，實際結果及未驗證項目見[部署與驗收](verification.md)。原快捷與釘選操作見[介面手冊](interface.md)。
