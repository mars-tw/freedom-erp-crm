# 外觀與快捷操作

頂欄的「外觀設定」提供暖紙淺色、深色工作台及依系統設定三種色彩模式。資訊密度可選舒適或精簡。外觀偏好保留在同一瀏覽器，調整時不會更新業務資料或執行交易；減少動態效果設定仍受尊重。

介面採原創 SVG 圖示、紙感底色與墨色層次，狀態與按鈕保留文字，操作不只依賴顏色。深色模式涵蓋清單、表單、搜尋、教學、提示及彈出視窗。

「快速新增」集中八種常用入口：客戶、商品、訂單、買家錢包、服務、製造工單、任務及里程碑。點選只開啟原有表單，按「確認模擬操作」才送出一筆操作。未啟用模組或缺少可用庫存、案件、BOM 等前置資料時，會顯示原因。搜尋、快速新增與編輯表單互斥，Esc 可關閉，鍵盤焦點回到原入口。

紀錄卡片可按「釘選」，工作總覽會保留最多二十四筆入口。釘選只保存紀錄參照，不複製客戶、金額或狀態；每次顯示都從目前工作區讀取最新名稱。取消釘選不刪資料。釘選保留於同一分頁，清除或匯入工作區後不會繼承上一個工作區的參照；此功能不是跨裝置同步。

待處理工作可切換全部、需要先處理或可接續。數量和分類取自實際工作區狀態，篩選只改顯示，不會自動付款、出貨、開工或修改進度。

瀏覽器阻擋儲存時，外觀與釘選可在本分頁記憶體繼續使用，但重新整理或關閉後可能失去偏好與參照。SIM、模擬商品、獨立訪客工作區與原操作確認流程均維持原有規則。

## 文案調整紀錄

| 原內容 | 原因 | 新內容 |
| --- | --- | --- |
| 只有單一配色與固定卡片間距 | 不同閱讀情境難以調整 | 暖紙、深色、系統配色及舒適／精簡密度 |
| 新增功能分散在各頁 | 常用操作需要多次切頁 | 快速新增沿用同一組確認表單與前置檢查 |
