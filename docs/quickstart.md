# 快速上手與一鍵建置

[開啟快速上手](https://freedom-erp-crm-demo.digimkt.workers.dev/#build)，依序完成三個步驟：

1. 選擇零售、批發、服務、餐飲、製造、電商、專案或一般企業範本。
2. 填店名並勾選功能。訂單、服務與製造需要的模組會一起啟用；關閉必要模組時，相依流程也會關閉。
3. 選「公開試用」或「在自己電腦建立」。公開試用只在確認後建立一次，再進入流程教學；已有工作區時會保留原資料，可以繼續操作或另下載本機建置包。

所有商品、錢包與付款都是模擬資料，幣別固定 SIM。建立時庫存及錢包為零，沒有自動交易；進貨、測試幣與後續流程由操作或教學逐步確認。

## 下載後啟動

先安裝 [Node.js 24 或更新版本](https://nodejs.org/en/download)及 [Git](https://git-scm.com/install/)。下載 `freedom-launch-kit.zip`，解壓到自己的短路徑資料夾，例如 Windows 的 `C:\freedom-shop`。啟動包需要網路下載公開 GitHub 專案與依賴；不會替你安裝 Node.js、變更執行原則或取得管理員權限。

- Windows：雙擊 `start.cmd`。
- macOS／Linux：在解壓資料夾的終端機執行 `sh start.sh`。
- 若系統限制啟動檔，在相同資料夾執行：

```sh
npx --yes github:mars-tw/freedom-erp-crm --config ./freedom-launch.json --open
```

系統檢查環境與設定後，自動下載並建置介面，選擇可用的本機連接埠。API 確認指定公司與模組就緒後，才開啟 `http://127.0.0.1:<port>/#learning`。若瀏覽器無法自動開啟，啟動視窗會提供可手動開啟的網址。第一次進入會建立指定的模擬工作區，不必重填建置表單。

啟動包包含設定 JSON、Windows／Shell 啟動檔、Node 啟動器、設定檢查程式、範本目錄及說明，共七個檔案。店名只作為 JSON 資料讀取，不會拼入執行指令。可以先檢查環境：

```sh
node launch.mjs --check
```

此檢查不安裝專案、不建立資料或啟動服務。若已安裝原始碼，可用 `node bin/freedom-erp.mjs --config <設定檔> --doctor` 檢查 UI 建置、執行環境、目錄權限、設定及連接埠；`--doctor` 也不寫入資料。

## 停止及接續

在原啟動視窗按 Ctrl+C 停止。再次開啟同一啟動檔，使用同一瀏覽器並保留 cookie，即可接續原訪客資料。資料存於設定檔旁的 `freedom-data/state`，名稱與模組設定存於 `freedom-data/instance.json`；不要刪除或搬動這些資料後仍期待自動接續。

本機每位訪客仍有獨立資料。清除瀏覽器 cookie 或換瀏覽器會進入另一個工作區；本機持久化不是登入帳號或跨裝置同步。系統重新啟動不會重新種資料；已清除的工作區不會自動重建。自架沒有公開站的閒置清除期限，請定期匯出 JSON。

已有不同設定、非空的其他目錄、連結目錄或仍在執行的相同實例會拒絕覆寫。要建立第二間店，重新下載建置包並放在另一個資料夾。自動連接埠會避開已在執行的程式，不會替你停止其他服務；原埠被占用時可改選下一個可用埠，瀏覽器 cookie 不按埠隔離，同一瀏覽器可接續原資料。

Windows 的 workerd SQLite 儲存路徑須少於 260 字元。啟動器會在建立資料前檢查；若提示路徑太長，先把尚未啟動的建置包解壓至更短位置。macOS 與 Linux 提供相同啟動檔，實體環境尚未逐一驗證。

## 設定與限制

`freedom-launch.json` 使用 `freedom-erp-launch-v1` 格式。可設定產業、公司名稱、模組、`port`（`auto` 或 1024–65535）、相對資料目錄及 `auto_setup`；固定 `simulation:true`、`real_finance:false`。不能指定任意命令、安裝來源或跳出設定檔資料夾的 `..` 路徑。設定與既有實例不符時請另開新資料夾。

`--config` 不能與舊式 `--industry`、`--name`、`--modules`、`--directory` 或 `--port` 混用。舊參數仍可使用，保留手動初次建置；`--dry-run` 只產生設定。只有自架且 `AUTO_SETUP=true` 的全新訪客會自動初始化；公開站忽略該旗標，仍須明確確認建立。

公開站資料在 72 小時無活動後清除。本系統沒有真銀行、正式會計、發票、物流、團隊帳號或產業法遵功能。匯入封裝上限 32 KB，大型匯出不能宣稱皆能以目前上限還原。驗證紀錄及未驗證項目見[部署與驗收](verification.md)。
