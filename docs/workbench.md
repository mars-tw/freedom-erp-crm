# 日常工作台

建立工作區後，頂欄的「搜尋工作區」可搜尋客戶、商機、聯絡人、案件、報價、商品、錢包、訂單、服務、BOM、工單、任務及里程碑。也可在沒有編輯輸入框或表單時按 Ctrl／Cmd＋K。搜尋會比對名稱、商品編號、備註及實際關聯資料，支援全形英數與多個關鍵字。選擇結果只會切換模組、清除篩選並定位紀錄，不執行付款或更新。

各清單提供搜尋、狀態篩選及每頁十二筆分頁。篩選後的訂單仍使用原本序號。沒有結果時可清除篩選；全站搜尋先顯示五十筆，再按「載入更多搜尋結果」查看其餘資料。

工作總覽的「待處理工作」依目前資料顯示下一步。餘額為零會帶到買家錢包，材料不足會帶到缺料商品；條件足夠時才建議付款、出貨、備料或開工。它是一份可核對的清單，不會自動執行操作。取消、完成及完整退貨不會被列為一般待辦；部分退貨後仍有已付款但未出貨的數量，則會保留出貨待辦。

紀錄卡片會說明目前條件及不足原因，並提供「前往處理」連結。餘額不足以付清時仍可部分付款，實際金額、庫存與狀態由伺服器再次檢查。

教學的「到工作台核對」能定位到該步驟的客戶、商品、錢包、報價、服務、訂單或工單。回到教學後，原章節與進度保留。缺少本次已確認操作紀錄的步驟會開啟對應模組，不會猜一筆資料冒充結果。

任務及里程碑可設定「到期時間」。輸入採瀏覽器本機時間，儲存時轉成 ISO 時間；清空會移除期限。未完成且過期的紀錄會列為需要處理的工作。這不是背景通知或寄信服務，頁面只依當下讀取的資料判斷。

瀏覽器無法寫入接續資訊時，原操作先保存在本分頁記憶體。結果尚未確認時，畫面會提醒先按「確認原操作結果」，再重新整理；關閉或重新整理不能保證保留未寫入的資訊。恢復使用原識別碼、參數與版本，不會再建立一筆同樣的交易。

所有功能仍只使用 SIM、模擬商品及獨立訪客資料，不提供真銀行、正式會計、發票或物流連線。

## 文案調整紀錄

| 原內容 | 原因 | 新內容 |
| --- | --- | --- |
| 各模組直接列出全部卡片 | 紀錄增加後難以找到目標 | 新增搜尋、狀態篩選、分頁與精準定位 |
| 按鈕不能操作時只有停用狀態 | 不容易知道缺少什麼 | 卡片列出餘額、材料或交付條件，並連到需處理的紀錄 |
| 工作總覽只顯示數量與模組入口 | 無法掌握尚未接續的工作 | 新增從實際狀態整理的待處理清單 |
